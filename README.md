### Selected Work

**Yupcha AI Interviewer** — Re-architected an AI video interviewer from a high-latency STT → LLM → TTS pipeline into real-time speech-to-speech using Python, Pipecat, AWS Bedrock Nova Sonic, LiveKit, and WebRTC. Designed the service architecture to support 100 concurrent live sessions, with asynchronous LLM scoring decoupled from live sessions. :chatgpt-content-reference{index="0"}

**AHTML** — Created a machine-readable HTML standard that generates OpenAPI 3.1, JSON-LD, `llms.txt`, and WebMCP from a single source. Published 9 npm packages with 25k+ combined downloads. :chatgpt-content-reference{index="1"}

**Kasauti** — Built an AI-powered assessment platform where an LLM authors questions, runs timed exams, auto-grades submissions, and provides per-topic analytics. Exposed the platform through MCP so agents can create exams, grade submissions, and generate targeted follow-up exams from weak areas. :chatgpt-content-reference{index="2"}

**Fresco** — Built and maintain an open-source Linux live wallpaper engine in Rust with a native GTK4 interface and optimized async playback pipeline. Reached 1,713 users across 115 countries and 5,695 downloads. :chatgpt-content-reference{index="3"}

**WhatBroke** — Built an AI debugging CLI and MCP server that packages crash context and uses Git history to identify suspect commits across multiple test runners. :chatgpt-content-reference{index="4"}
